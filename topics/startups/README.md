## 如果只读一篇

读 **[Do Things that Don't Scale](ds.md)**（做不可扩展的事）。这篇浓缩了 Y Combinator 的核心哲学：伟大的创业公司都是从做那些"不可扩展"的事情开始的——手动招募用户、亲自做客服、做那些不能自动化的笨事。这是对"先做产品等用户自己来"这一幻想的最好解毒剂。
