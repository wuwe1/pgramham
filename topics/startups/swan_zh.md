# 黑天鹅养殖

> Source: [https://paulgraham.com/swan.html](https://paulgraham.com/swan.html)

---

**想创办一家初创公司？** 来
[Y Combinator](http://ycombinator.com/apply.html) 获得资助。


2012年9月

这些年来我做过好几种不同类型的工作，但我不知道还有哪一种比初创公司投资更违反直觉。

要理解初创公司投资这门生意，最重要的两件事是：（1）几乎所有的回报都集中在少数几个大赢家身上，以及（2）最好的创意最初看起来像是糟糕的创意。

第一条规则我在理智上是知道的，但直到它真正发生在我们身上，我才真正领悟。我们投资过的公司总价值大约在100亿左右。但仅仅 Dropbox 和 Airbnb 两家公司，就占了其中大约四分之三。

在初创公司领域，大赢家的巨大程度违背了我们对差异性的预期。我不知道这些预期是天生的还是后天习得的，但无论原因是什么，我们就是没有为初创公司投资中1000倍的结果差异做好准备。

这产生了各种奇怪的后果。例如，从纯粹的财务角度来看，每一批 YC 项目中可能最多只有一家公司会对我们的回报产生重大影响，其余的都只是经营成本。
[[1](#f1n)]
我并没有真正消化这个事实，部分原因是它太违反直觉了，部分原因是我们做这件事不仅仅是为了财务回报；如果每批只有一家公司的话，YC 会是一个相当孤独的地方。然而这是事实。

要在一个违反你直觉的领域取得成功，你需要能够像飞行员在云中飞行时那样关闭直觉。
[[2](#f2n)]
你需要去做你理智上知道是正确的事情，即使感觉上是错的。

这对我们来说是一场持续的战斗。要让自己承担足够的风险很难。当你面试一家初创公司，觉得"他们看起来很可能会成功"的时候，很难不去投资他们。然而，至少从财务角度来看，只有一种成功：他们要么会成为真正的大赢家，要么不会。如果不会，那你投不投资他们都无所谓，因为即使他们成功了，对你回报的影响也微不足道。在同一天的面试中，你可能会遇到一些聪明的19岁年轻人，他们甚至还不确定自己想做什么。他们成功的概率看起来很小。但同样，重要的不是他们成功的概率，而是他们取得巨大成功的概率。任何一个团队取得巨大成功的概率都是微乎其微的，但那些19岁年轻人的概率可能比那个更安全的团队还要高。

一家初创公司做大的概率并不简单地是它成功概率的某个固定比例。如果是的话，你只要投资所有看起来可能成功的公司，就能获得相应比例的大赢家。不幸的是，挑选赢家比这要难得多。你必须忽略眼前的大象——他们成功的可能性——而专注于另一个几乎看不见的、无形的问题：他们是否会取得巨大成功。

**更难**

这件事之所以更难，是因为最好的初创公司创意最初看起来像是糟糕的创意。我之前写过这个话题：如果一个好创意明显是好的，那别人早就做了。所以最成功的创始人往往在做只有他们自己才意识到是好的创意。这和疯狂的描述相差不远，直到你看到结果。

Peter Thiel 第一次在 YC 演讲时画了一个完美诠释这种情况的维恩图。他画了两个相交的圆，一个标注"看起来像坏主意"，另一个标注"是好主意"。交集就是初创公司的甜蜜点。

这个概念很简单，但以维恩图的形式来看却很有启发性。它提醒你交集是存在的——确实有看起来糟糕的好创意。它也提醒你，绝大多数看起来糟糕的创意确实是糟糕的。

最好的创意看起来像坏创意这一事实，使得识别大赢家变得更加困难。这意味着一家初创公司真正做大的概率不仅不是它成功概率的某个固定比例，而且那些前者概率高的初创公司，后者的概率看起来反而会不成比例地低。

历史往往被大成功所改写，以至于回头看来它们注定会成功似乎是显而易见的。因此，我最宝贵的记忆之一是当我第一次听说 Facebook 时觉得它有多无聊。一个让大学生浪费时间的网站？它看起来像是完美的坏主意：一个网站，（1）面向小众市场，（2）用户没有钱，（3）做一件无关紧要的事情。

人们完全可以用同样的话来描述 Microsoft 和 Apple。
[[3](#f3n)]

**难上加难**

等等，还有更糟的。你不仅要解决这个难题，而且在解题过程中完全没有任何指标告诉你是否在做对。当你选中一个大赢家时，你要两年后才能知道。

与此同时，你唯一**能**衡量的东西却是危险地误导性的。我们唯一能精确追踪的指标是每批初创公司在 Demo Day 之后的融资情况。但我们知道这是错误的指标。在融资成功的初创公司比例和真正重要的财务指标——那一批中是否包含大赢家——之间，没有任何正相关。

反而有负相关。这才是可怕的地方：融资情况不仅是一个无用的指标，而且是积极误导的。我们的业务需要我们挑选看起来不太有前途的异类，而巨大的成功规模意味着我们可以把网撒得非常广。大赢家可以产生10,000倍的回报。这意味着每有一个大赢家，我们可以投资一千家颗粒无收的公司，最终仍然获得10倍的收益。

如果我们投资的初创公司100%都能在 Demo Day 之后融到资，那几乎可以肯定意味着我们太保守了。
[[4](#f4n)]

不这样做也需要刻意的努力。经过15轮为初创公司准备面对投资者、然后观察它们表现的循环后，我现在可以用 Demo Day 投资者的眼光来审视我们正在面试的团队。但那是错误的眼光！

我们可以承担比 Demo Day 投资者至少多10倍的风险。既然风险通常与回报成正比，如果你能承担更多风险，你就应该这样做。承担比 Demo Day 投资者多10倍的风险意味着什么？我们必须愿意投资比他们多10倍的初创公司。这意味着即使我们对自己宽容一点，假设 YC 平均能使一家初创公司的期望价值提高三倍，如果只有30%的初创公司能在 Demo Day 之后融到大笔资金，我们承担的风险才是合适的。

我不知道目前有多少比例的初创公司在 Demo Day 之后能融到更多资金。我刻意避免计算这个数字，因为一旦你开始衡量某样东西，你就会开始优化它，而我知道它是不该优化的东西。
[[5](#f5n)]
但这个比例肯定远超30%。坦率地说，30%的融资成功率这个想法让我感到胃紧缩。如果一个 Demo Day 只有30%的初创公司能融到资，那将是一场灾难。所有人都会认为 YC 已经过气了。我们自己也会觉得 YC 已经过气了。然而我们都会是错的。

不管是好是坏，这永远只会是一个思想实验。我们永远承受不了。这够违反直觉吧？我能清楚地阐述我知道是正确的做法，却仍然不去做。我能编出各种看似合理的理由。如果我们投资大量高风险、最终失败的初创公司，会损害 YC 的品牌（至少在不懂数学的人中间）。这可能会稀释校友网络的价值。也许最有说服力的理由是，整天泡在失败里对我们来说太令人沮丧了。但我知道我们如此保守的真正原因是，我们还没有消化回报存在1000倍差异这个事实。

我们可能永远无法让自己承担与这个行业回报相称的风险。我们能期望的最好结果是，当我们面试一个团队，发现自己在想"他们看起来像是好创始人，但投资者会怎么看这个疯狂的想法？"的时候，我们能继续说"谁在乎投资者怎么想？"这就是我们对 Airbnb 的想法，如果我们想投资更多的 Airbnb，我们就必须保持善于这样思考。





**注释**

[1]
我并不是说大赢家就是一切，只是说从投资者的财务角度来看，大赢家就是一切。由于我们做 YC 主要不是为了财务原因，大赢家并不是对我们来说最重要的。例如，我们很高兴投资了 Reddit。虽然我们从中赚得相对较少，但 Reddit 对世界产生了巨大影响，它还让我们认识了 Steve Huffman 和 Alexis Ohanian，他们两位都成了好朋友。

我们也不会逼迫创始人在不愿意的情况下去追求成为大赢家。我们自己的初创公司（Viaweb，以5000万美元被收购）也没有"全力挥棒"，如果我们逼创始人去做我们自己没做过的事，那会显得很虚伪。我们的规则是由创始人自己决定。有些人想要征服世界，有些人只想赚到第一个几百万。但我们投资了这么多公司，不需要对任何一个结果焦虑。事实上，我们甚至不需要焦虑初创公司是否有退出。唯一在财务上重要的是那些最大的退出，而这些在某种意义上是有保障的，因为如果一家公司变得足够大，其股份的市场必然会出现。由于其余的结果对回报没有显著影响，创始人想要早期以小金额出售，或者慢慢增长永不出售（即成为所谓的生活方式企业），甚至关闭公司，我们都没意见。当一家我们寄予厚望的初创公司表现不佳时，我们有时会感到失望，但这种失望基本上就是任何人在遇到这种情况时都会有的那种普通的失望。

[5]
