既然"拉面盈利"这个词已经广为流传，我应该精确解释一下这个概念的含义。

拉面盈利是指一家创业公司刚好赚到足够支付创始人生活费用的钱。这是一种不同于创业公司传统追求的盈利形式。传统的盈利意味着一个大赌注终于开始回报，而拉面盈利的主要意义在于它为你赢得了时间。[[1](#f1n)]

过去，一家创业公司通常要在筹集并花费了大量资金之后才能实现盈利。一家生产计算机硬件的公司可能需要5年才能盈利，期间花掉了5000万美元。但当它们盈利时，年收入可能达到5000万美元。这种盈利意味着创业公司已经成功了。

拉面盈利则是另一个极端：一家创业公司在2个月后就实现盈利，尽管月收入只有3000美元，因为唯一的员工是几个25岁的创始人，几乎不需要花什么钱。月收入3000美元并不意味着公司已经成功。但它与那种传统意义上盈利的公司有一个共同点：它们不需要融资来生存。

拉面盈利对大多数人来说是个陌生的概念，因为它直到最近才变得可行。对很多创业公司来说仍然不可行；比如对大多数生物技术创业公司就不适用；但对许多软件创业公司来说是可行的，因为它们现在成本非常低。对许多公司来说，唯一的真实成本就是创始人的生活费。

这种盈利类型的主要意义在于你不再受制于投资者。如果你仍在亏损，那么最终你要么必须再融资，要么关门。一旦你实现了拉面盈利，这个痛苦的选择就消失了。你仍然可以融资，但不必现在就做。

\* \* \*

不需要钱最明显的好处是你可以获得更好的条款。如果投资者知道你需要钱，他们有时会利用这一点。有些人甚至可能故意拖延，因为他们知道随着你的钱快用光，你会变得越来越容易妥协。

但拉面盈利还有三个不那么明显的好处。其一是它让你对投资者更有吸引力。如果你已经盈利了，无论规模多小，它表明 (a) 你至少能让某些人愿意付费，(b) 你认真地在做人们想要的东西，(c) 你有足够的纪律性来控制开支。

这让投资者感到安心，因为你已经解决了他们最大的三个担忧。他们常常投资那些有聪明创始人和大市场的公司，结果仍然失败。当这些公司失败时，通常是因为 (a) 人们不愿为他们做的东西付费，比如因为太难卖给他们，或者市场还没准备好，(b) 创始人解决了错误的问题，而没有关注用户的需求，或者 (c) 公司花费太多，在开始赚钱之前就烧光了资金。如果你已经实现了拉面盈利，你已经在避免这些错误了。

拉面盈利的另一个好处是它有利于士气。一家公司刚创办时往往感觉相当虚幻。它在法律上是一家公司，但你称它为公司时会觉得自己在撒谎。当人们开始向你支付可观的金额时，公司开始变得真实。而你自己的生活费用是你感受最深的里程碑，因为在那个节点，未来的状态翻转了。现在存活成了默认状态，而不是死亡。

在创业公司中，如此大幅度的士气提升是非常宝贵的，因为经营创业公司的心理负担才是它困难的原因。创业公司仍然非常稀少。为什么不是更多人去做？经济风险？很多25岁的年轻人本来就什么都存不下。长时间工作？很多人在普通工作中也工作同样长的时间。阻止人们创业的是承担如此多责任的恐惧。而这不是非理性的恐惧：这确实是很重的负担。任何能减轻这种负担的事情都会大大增加你存活的机会。

一家达到拉面盈利的创业公司成功的可能性可能大于失败的可能性。考虑到创业公司结果的双峰分布——你要么失败，要么赚大钱——这相当令人兴奋。

拉面盈利的第四个好处最不明显，但可能是最重要的。如果你不需要融资，你就不必中断公司的工作去融资。

[融资](fundraising.html)极其令人分心。如果你的生产力能达到之前的三分之一，就算幸运了。而且融资可能持续数月。

我直到今年早些时候才理解（或者说想起来）融资为什么如此令人分心。我注意到我们投资的创业公司在转向融资时通常会陷入停滞，但我一直不记得确切原因，直到 YC 自己进行了融资。我们的过程相对容易；我问的第一批人就答应了；但花了几个月来敲定细节，在那段时间里我几乎没完成什么真正的工作。为什么？因为我无时无刻不在想这件事。

在任何时候，创业公司往往有一个最紧迫的问题。这就是你晚上入睡时和早上洗澡时想的事情。当你开始融资时，那就成了你想的问题。你早上只洗一次澡，如果洗澡时在想投资者的事，那你就没在想产品。

而如果你可以选择何时融资，你可以挑一个不在忙其他事情的时候，而且你大概还能要求这轮融资快速完成。如果你不在乎融资是否能成，你甚至可能避免让融资占据你的思绪。

\* \* \*

拉面盈利的含义不多不少就是其定义所蕴含的。例如，它并不意味着你在"自力更生"——你永远不会从投资者那里拿钱。从经验来看，那似乎效果不太好。很少有创业公司不接受投资就能成功。也许随着创业变得越来越便宜，这会变得更常见。另一方面，钱就在那里，等着被投资。如果创业公司不那么需要钱了，它们就能以更好的条款获得投资，这会让它们更倾向于接受投资。这往往会产生一种均衡。[[2](#f2n)]

拉面盈利也不意味着 Joe Kraus 的那个观点，即你应该在产品进入测试版时就把你的[商业模式](http://www.brendonwilson.com/blog/2006/04/30/joe-kraus-confessions-of-a-startup-addict/)也放进测试版。他认为你应该从一开始就让人们付费。我觉得这太有局限性了。Facebook 没有这样做，而他们比大多数创业公司做得更好。对他们来说，立刻赚钱不仅不必要，而且可能有害。不过我确实认为 Joe 的规则对许多创业公司可能有用。当创始人看起来缺乏专注时，我有时会建议他们试着让客户为某些东西付费，希望这种约束能促使他们行动起来。

Joe 的想法和拉面盈利之间的区别在于，一家拉面盈利的公司不必以其最终的方式赚钱。它只需要在赚钱就行。最著名的例子是 Google，它最初通过向 Yahoo 等网站授权搜索来赚钱。

拉面盈利有没有什么坏处？最大的危险可能是它会把你变成一家咨询公司。创业公司必须是产品公司，即做一个所有人都使用的东西。创业公司的定义特征是它们增长快，而咨询就是无法像产品那样扩展。[[3](#f3n)] 但每月赚3000美元做咨询相当容易；事实上，对于合同编程来说这算是很低的费率。所以可能会有一种诱惑，让你滑入咨询的模式，然后告诉自己你是一家拉面盈利的创业公司，而实际上你根本不是创业公司。

一开始做一点咨询类的工作是可以的。创业公司在初期通常不得不做一些奇怪的事情。但请记住，拉面盈利不是终点。创业公司的终点是做大；拉面盈利是在途中[不死掉](die.html)的一个技巧。



**注释**

[1]
"拉面盈利"中的"拉面"指的是方便面，这几乎是你能买到的最便宜的食物。

请不要从字面意义理解这个词。只吃方便面会非常不健康。米饭和豆子是更好的食物来源。如果你没有电饭锅的话，先买一个。

米饭和豆子（2n人份）

```
  橄榄油或黄油
  n 个黄洋葱
  其他新鲜蔬菜；自由发挥
  3n 瓣大蒜
  n 罐12盎司的白豆、红腰豆或黑豆
  n 块 Knorr 牛肉或蔬菜浓汤块
  n 茶匙现磨黑胡椒
  3n 茶匙磨碎的孜然
  n 杯干米，最好是糙米
```

把米放进电饭锅。按米包装上的说明加水。（默认：每杯米加2杯水。）打开电饭锅，然后就不用管了。

切洋葱和其他蔬菜，用油以较低的火候煎炒，直到洋葱变得透明。放入切碎的大蒜、胡椒、孜然和多一点油脂，搅拌。保持小火。再煮2到3分钟，然后加入豆子（不要沥干豆子的汁），搅拌。扔入浓汤块，盖上锅盖，以较小的火再煮至少10分钟。勤快搅拌以避免粘锅。

如果你想省钱，在折扣店买大罐豆子。大量购买香料也便宜得多。如果你附近有印度杂货店，他们会有大袋装的孜然，价格和超市里那些小瓶装的一样。

[2]
权力从投资者转移到创始人很可能实际上会增加风险投资行业的规模。我认为目前投资者对创始人过于苛刻了。如果他们被迫停止这样做，整个风险投资行业会运转得更好，你可能会看到类似于取消限制性法规时总能看到的贸易增长。

投资者是创始人最大的痛苦来源之一；如果他们不再造成那么多痛苦，当创始人就会更好；如果当创始人更好了，就会有更多人去做。

[3]
可以想象，一家创业公司可以通过将咨询转变为可扩展的形式来做大。但如果他们做到了，他们实际上就是一家产品公司。
